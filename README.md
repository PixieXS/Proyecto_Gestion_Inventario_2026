# Inventoryx

Controla tu inventario con mas orden, mas seguridad y menos trabajo manual.

`Inventoryx` es un sistema de gestion de inventario para escritorio disenado para negocios que necesitan registrar productos, controlar entradas y salidas, consultar reportes y mantener trazabilidad de cada movimiento en un solo lugar.

## Por que elegir Inventoryx

- Centraliza productos, categorias, proveedores y usuarios.
- Reduce errores con validaciones y controles de seguridad.
- Registra cada entrada y salida con historial y confirmacion.
- Detecta stock critico y ayuda a tomar decisiones a tiempo.
- Genera reportes utiles para seguimiento operativo.
- Facilita cargas masivas desde Excel.
- Protege la informacion con auditoria y respaldos.

## Funciones principales

### Inventario en tiempo real

Administra productos con datos como:
- Nombre
- Codigo o SKU
- Categoria
- Proveedor
- Precio de compra y venta
- Stock minimo y maximo
- Unidad de medida

### Entradas y salidas con mayor seguridad

Cada movimiento de inventario puede quedar respaldado con:
- Registro del usuario que realiza la accion
- Nota descriptiva del movimiento
- Confirmacion con contrasena antes de guardar entradas o salidas
- Validacion para evitar stock negativo

### Reportes para control y analisis

Consulta reportes como:
- Resumen general
- Stock critico
- Productos sin movimiento
- Inventario valorizado
- Movimientos por usuario
- Reporte por proveedor
- Comparativos por fechas
- Entradas vs salidas

### Importacion masiva

Agrega productos desde archivos Excel para ahorrar tiempo y reducir digitacion manual.

### Gestion administrativa

Controla:
- Usuarios
- Roles y permisos
- Proveedores
- Categorias
- Auditoria del sistema
- Backups y restauraciones

## Ideal para

`Inventoryx` es una buena opcion para:
- Tiendas y comercios
- Bodegas y almacenes
- Negocios con control de stock por producto
- Empresas que necesitan trazabilidad de movimientos
- Equipos que desean reportes claros sin procesos complicados

## Beneficios para tu operacion

- Menos perdida de tiempo buscando informacion.
- Menos errores por registros manuales.
- Mejor control del stock disponible.
- Mayor seguridad en movimientos sensibles.
- Mejor seguimiento de usuarios y acciones.
- Informacion lista para tomar decisiones.

## Seguridad y control

El sistema incluye medidas como:
- Confirmacion con contrasena en acciones sensibles
- Bloqueo temporal por intentos fallidos de inicio de sesion
- Cierre por inactividad
- Historial de actividad
- Respaldo de base de datos

## Experiencia de uso

La interfaz esta pensada para trabajar de forma practica:
- Dashboard con indicadores clave
- Alertas de stock critico
- Busquedas y filtros rapidos
- Mensajes visuales de confirmacion
- Formularios claros para captura y actualizacion

## Como empezar

1. Abra la aplicacion.
2. Inicie sesion con su usuario y contrasena.
3. Configure o cargue sus productos.
4. Registre entradas y salidas conforme ocurran.
5. Consulte reportes y alertas desde el panel principal.
